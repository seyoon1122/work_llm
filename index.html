미토콘드리아 유전암호표의 예외성 비교

유전암호는 정말 보편적일까요? 미토콘드리아에서는 표준 암호표에서 '종결'인 TGA가 트립토판(W)을 지정합니다. 같은 DNA도 어떤 암호표를 쓰느냐에 따라 단백질이 중간에 끊깁니다. 데이터 분석에서 생물학적 가정이 왜 중요한지 직접 확인해 보세요.

직접 번역해 보기

왜 이 주제인가?

1. 가정의 함정

Biopython의 translate() 기본값은 표준 암호표(table 1)입니다. 미토콘드리아 DNA를 그대로 넣으면 TGA에서 번역이 끊기는 오역이 생깁니다.

2. 실험 설계

TGA 등이 포함된 짧은 DNA를 표준(table 1)과 척추동물 미토콘드리아(table 2)로 각각 번역하고, 결과를 CSV로 저장합니다.

3. 시각화

Matplotlib 막대그래프로 두 조건에서 번역된 아미노산 길이를 나란히 비교합니다. 아래 데모는 같은 그래프를 브라우저에서 그립니다.

표준 vs 미토콘드리아 암호표: 차이 코돈

척추동물 미토콘드리아 암호표(NCBI table 2) 기준입니다. 이 4개 코돈만 표준과 다릅니다.

코돈표준 (table 1)미토콘드리아 (table 2)의미
TGA종결 (*)트립토판 (W)종결 → 아미노산
ATA이소류신 (I)메싸이오닌 (M)아미노산 변경
AGA아르지닌 (R)종결 (*)아미노산 → 종결
AGG아르지닌 (R)종결 (*)아미노산 → 종결

인터랙티브 번역 데모

이름DNA 길이(nt)표준 번역표준 길이(aa)미토 번역미토 길이(aa)차이진단

길이는 Biopython의 translate(table, to_stop=True)와 같이 첫 종결 코돈 전까지 센 값입니다. *는 종결 코돈입니다.

번역된 아미노산 길이 비교

재현용 Python 코드

from Bio.Seq import Seq
import pandas as pd
import matplotlib.pyplot as plt

seqs = {
    "mt_ND1_like": "ATGTTCATAGCCTGAACAGGAGGATAA",
    "TGA_internal": "ATGGCCTGAAAATGACTGTAG",
    "AGA_stop": "ATGCTAATAAGAGCTGGATAA",
    "no_exception": "ATGAAACCCGGGTTTTAA",
}
rows = []
for name, s in seqs.items():
    dna = Seq(s)
    std = str(dna.translate(table=1, to_stop=True))
    mt  = str(dna.translate(table=2, to_stop=True))
    rows.append({"name": name, "standard": std, "mito": mt,
                 "len_standard": len(std), "len_mito": len(mt)})

df = pd.DataFrame(rows)
df.to_csv("translation_comparison.csv", index=False)

ax = df.set_index("name")[["len_standard", "len_mito"]].plot(kind="bar")
ax.set_ylabel("Translated length (aa)")
plt.tight_layout()
plt.savefig("length_comparison.png", dpi=200)

핵심 교훈의 해결: 기본값에 의존하지 않기

  1. 항상 table을 명시합니다. 핵 유전자는 table=1, 척추동물 미토콘드리아는 table=2로 씁니다. 기본값을 암묵적으로 쓰지 않습니다.
  2. 번역 후 검증합니다. 내부 종결 코돈(*)이 있으면 암호표 가정이 틀렸다는 신호입니다. 위 데모의 '진단' 열이 이 검사를 합니다.
  3. 기록합니다. 어떤 암호표를 썼는지 CSV 열(table)과 그래프 제목에 남겨 재현성을 높입니다.
def translate_checked(dna, table):
    prot = str(Seq(dna).translate(table=table))        # table 명시
    if "*" in prot[:-1]:                               # 내부 종결 코돈 검사
        print(f"경고: table={table}에서 내부 종결 코돈 -> 암호표 가정 확인!")
    return prot

for name, s in seqs.items():
    translate_checked(s, 1)   # 미토콘드리아 DNA에 table=1 -> 경고 발생
    translate_checked(s, 2)   # 올바른 가정 -> 경고 없음
